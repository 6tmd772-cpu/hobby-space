# HOBBY SPACE 개발 기록

## 1. 프로젝트 개요

- **프로젝트명:** HOBBY SPACE
- **프로젝트 목적:** 취미별 게시판을 통해 사용자들이 관심 분야의 정보를 공유하고 소통할 수 있는 커뮤니티 제작
- **개발 방식:** AI를 활용한 바이브 코딩
- **개발 환경:** React, Vite, Supabase, Antigravity IDE
- **소스 코드 저장소:** https://github.com/6tmd772-cpu/hobby-space

## 2. 개발 목표

단순 게시판에서 시작하여 여러 취미별 게시판을 제공하는 다중 게시판으로 확장하고, 최종적으로 관리자 권한에 따라 게시판을 관리할 수 있는 복합 다중 게시판을 구현하는 것을 목표로 하였다.

## 3. 주요 구현 기능

### 3-1. 기본 기능
- 회원 로그인 기능
- 닉네임 표시
- 게시글 작성 및 조회
- 게시글 수정 및 삭제
- 댓글 작성 및 조회
- 댓글 삭제

### 3-2. 다중 게시판 기능
- BOOK SPACE
- GAME SPACE
- MUSIC SPACE
- COOK SPACE
- ACTIVE SPACE
- 전체 게시판 통합 피드
- 취미별 게시판 이동 기능

### 3-3. 테스트 모드
- 전체 관리자 테스트 계정
- 취미별 관리자 테스트 계정 5개
- 일반 회원 테스트 계정 2개
- 개발 환경에서 테스트 역할을 전환하는 기능

## 4. 개발 과정

1. React와 Vite를 이용한 게시판 프로젝트 생성
2. Supabase 연동 및 회원 로그인 기능 구현
3. 게시글 저장 및 조회 기능 구현
4. 닉네임 표시 기능 추가
5. 댓글 저장 및 조회 기능 구현
6. 취미별 게시판 구성 및 통합 피드 구현
7. 관리자와 일반 회원의 역할을 확인하기 위한 테스트 모드 추가
8. GitHub를 이용한 프로젝트 버전 저장 및 백업

## 5. 데이터베이스

- Supabase를 데이터 저장소로 사용하였다.
- 회원 프로필, 게시글, 댓글 데이터를 관리하도록 구성하였다.
- 게시글과 댓글의 저장 및 조회 기능을 구현하였다.

## 6. AI 활용 및 개발 기록

- **사용 도구:** Antigravity IDE
- **개발 방식:** 요구사항을 프롬프트로 전달하고 AI가 생성한 코드를 실행하여 결과를 확인하는 방식으로 진행하였다.
- **주요 요청 사항:** 게시판 생성, Supabase 연동, 게시글 및 댓글 기능, 취미별 게시판 구성, 테스트 역할 전환 기능
- **오류 해결 과정:** 게시글과 댓글 저장 과정에서 발생한 오류를 분석하고 수정하도록 AI에 요청하였다.
- **개선 과정:** 실행 결과를 확인한 후 필요한 수정 사항을 단계적으로 전달하였다.

※ 실제 사용한 프롬프트와 AI 응답은 별도 기록 자료를 추가하여 보완할 수 있다.
